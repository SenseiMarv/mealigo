# Mealie Go

Mealie Go lets people access their Mealie instance from a mobile device.

## Language

**Mealie instance**:
A running Mealie installation that a person accesses using its URL.
_Avoid_: Mealie Go server

**Server connection**:
The URL and optional custom headers used to access a Mealie instance.
_Avoid_: Account

**Mealie account**:
A person's identity within a Mealie instance, used to access their recipes and meal planning.
_Avoid_: Server connection, Mealie Go account
